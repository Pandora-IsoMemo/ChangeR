# Info Button UI

Info Button UI

Info Button Server

## Usage

``` r
infoButtonUI(id, label = "Description")

infoButtonServer(id, title = "Description", text, link = NULL)
```

## Arguments

- id:

  The module id

- label:

  The label of the button

- title:

  The title of the modal

- text:

  The text to display in the modal

- link:

  The link to the documentation
