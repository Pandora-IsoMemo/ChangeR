# Run mcp model

Run mcp model

## Usage

``` r
runMcp(lists, ...)
```

## Arguments

- lists:

  A list of lists containing the segmented formulas and priors, output
  of
  [`setFormulasAndPriors()`](https://pandora-isomemo.github.io/ChangeR/reference/setFormulasAndPriors.md)

- ...:

  Additional arguments to pass to mcp

## Value

A list of mcp model fits
