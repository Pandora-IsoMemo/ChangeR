# MCP Model Summary UI

MCP Model Summary UI

MCP Model Summary Server

## Usage

``` r
mcpModelSummaryUI(id)

mcpModelSummaryServer(id, mcpData, formulasAndPriors, mcpFitList)
```

## Arguments

- id:

  The module id

- mcpData:

  The reactive mcp data

- formulasAndPriors:

  The reactive formulas and priors

- mcpFitList:

  The reactive mcp fit list
