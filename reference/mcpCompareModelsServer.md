# MCP Compare Models UI

MCP Compare Models UI

MCP Compare Models Server

## Usage

``` r
mcpCompareModelsUI(id)

mcpCompareModelsServer(id, formulasAndPriors, mcpData, mcpFitList)
```

## Arguments

- id:

  The module id

- formulasAndPriors:

  The reactive formulas and priors

- mcpData:

  The reactive mcp data

- mcpFitList:

  The reactive mcp fit list
